## 관리자 미래 날짜 캐시

- 관리자 날짜 범위 캐시에서 오늘 이후 날짜도 선택할 수 있도록 제한을 제거했다.
- 관리자 범위 작업은 미래 날짜를 포함해 최대 366일까지 순차적으로 캐시한다.
- 미래 날짜도 관리자 강제 캐시 시 메뉴와 이미지를 함께 웰스토리에서 받아 저장한다.
- 이미지까지 모두 저장된 미래 식단은 공개 화면에서 `READY`로 표시한다.

### 구현 내용

- 메뉴가 1~3개인 응답만 특식으로 판정하며, 메뉴가 0개인 대기/휴무 응답은 특식으로 처리하지 않는다.
- 특식인 오늘은 Hero 문구를 `오늘, 뭐 먹을까요?`에서 `오늘 특식 뭐 먹을까요?`로 바꾼다.
- Hero 문구가 작게 시작해 폭발적으로 커지는 컷인 효과를 내며, `특식` 단어는 주변 글자보다 8px 크게 표시한다.
- `특식` 단어 중심에서 파티클이 사방으로 퍼진 뒤 각자 다른 중력값으로 아래로 천천히 내려오며 사라진다.
- 메뉴 목록 헤더에는 별도의 `🎉 특식` 배지를 표시하지 않는다.
- `prefers-reduced-motion: reduce` 환경에서는 파티클과 애니메이션을 숨기고 특식 문구만 표시한다.
- 축하 효과는 Hero 문구 안에서만 표시하며, 메뉴 목록에는 별도 특식 배지를 추가하지 않는다.
