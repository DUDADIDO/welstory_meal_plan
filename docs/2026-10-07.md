# 2026-10-07 작업 기록

## 식단별 익명 채팅

- 날짜와 식단 ID별로 채팅방을 구분하고 식단 카드에 입장 버튼을 추가했다.
- 입장 버튼은 기존 별점 영역 오른쪽의 채팅 아이콘으로 배치하고, 별도의 버튼 행을 없앴다.
- 음식 이름 200개에서 서로 다른 두 개를 무작위로 조합해 중복 없는 익명 이름을 부여한다.
- 서버가 발급한 HttpOnly 쿠키로 사용자를 구분하며 이름과 메시지를 PostgreSQL에 보관한다.
- 모든 방을 합산해 사용자당 5초에 1개, 한국 시간 기준 하루 50개로 전송을 제한한다.
- 사용자 행 잠금과 트랜잭션으로 여러 탭·서버 인스턴스의 동시 요청에도 같은 제한을 적용한다.
- 채팅방은 3초마다 갱신하며 남은 일일 횟수, 전송 대기 시간, 이전 대화 조회를 제공한다.
- `V2__meal_chat.sql` 마이그레이션과 운영 DB와 분리된 Docker 통합 테스트 환경을 추가했다.

## 검증

- React 프로덕션 빌드와 Java 21 서버 패키징을 완료했다.
- 기존 테스트 14개와 채팅 PostgreSQL·HTTP 통합 테스트 9개가 통과했다.
- 5초 경계, 50개 제한, 한국 시간 자정 초기화, 자정을 넘는 전송 간격을 확인했다.
- 동시 전송 12건 중 1건만 저장되는 것과 사용자 구분·쿠키·요청 검증·이전 기록 조회를 확인했다.

## 적용

운영 반영은 `docker compose up -d --build`로 진행한다. 서버 기동 시 Flyway가 채팅 테이블을 생성한다.
사용자 구분은 브라우저 쿠키 기준이므로 다른 브라우저, 시크릿 창, 쿠키 삭제 후에는 새 익명 사용자로 처리된다.
